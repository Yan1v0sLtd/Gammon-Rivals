# Archived migrations (pre-baseline)

These 74 files are the project's migration history up to 2026-06-12. They are
**archived, not active**: the live database's schema had drifted from this
sequence via out-of-band changes (audit finding D-REL-1), so replaying these
files onto a fresh database fails partway through (first symptom:
`table_configs` referenced before it exists).

They were superseded by a single verified baseline:

```
supabase/migrations/20260612100000_baseline_schema.sql
```

generated by server-side catalog introspection of the live production schema
(`pg_get_functiondef` / `pg_get_constraintdef` / `pg_get_indexdef` /
`pg_policies` / `cron.job` / storage buckets / realtime publication / grants)
and **verified by rebuild**: a fresh Supabase preview branch was created so it
replayed only the baseline, then the same introspection dump was taken from
both databases and diffed — byte-identical, including the function ACL matrix.

The production migration history (`supabase_migrations.schema_migrations`)
was repaired to a single matching baseline row on the same date; the original
81 history rows are preserved in
`supabase_migrations.schema_migrations_backup_20260612` in the production
database.

**Do not add new files here and do not re-apply these.** New migrations go in
`supabase/migrations/` with a version greater than `20260612100000`, as usual.
These files are kept only as readable history of how the schema evolved.
